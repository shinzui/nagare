# Theme: team operation

Use cases in which Nagare serves people other than its operator, such as a workplace intranet. The
data is not the operator's alone, colleagues sign in to it, and the installation must stay
recoverable and auditable for them.

The theme covers requirements the workplace states: who operates the platform, who approves
changes, what is audited, how data is protected and recovered, and how users reach it. A
requirement belongs here only once the operator has stated it. Multi-operator features are planned
only when a use case under this theme asks for them.
