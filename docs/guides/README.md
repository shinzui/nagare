# Nagare guides

These guides are goal-oriented walkthroughs that combine several parts of
Nagare into an operating pattern. They complement the
[user manual](../user/README.md): `docs/user` documents individual features and
commands, while `docs/guides` explains how to use those features together to
achieve a larger outcome.

## Guides

- [Running multiple Nagare clusters](running-multiple-clusters.md) — choose
  cluster boundaries, provision `prod`, `labs`, and `local` targets, keep their
  state and domains isolated, and pair each Nagare context with the correct
  Kubernetes endpoint.

Each guide states its supported topology and links back to the authoritative
user-manual pages for command and configuration details.
