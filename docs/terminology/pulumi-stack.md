# Pulumi stack

The per-context Pulumi state and configuration used to manage Nagare cloud resources. A context selects a stack and state backend. The stack tracks resources such as the VM, IP address, disks, DNS, and backup bucket.

See [Provisioning with pulumi](../../docs/user/provisioning-with-pulumi.md) for the full contract and operating procedure.
