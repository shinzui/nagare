# local mode

The Nagare operating mode that runs the application platform on k3d with a local registry and MinIO. A local context uses loopback addresses and does not provision a GCP VM. It is useful for development and platform smoke tests.

See [Local development](../../docs/user/local-development.md) for the full contract and operating procedure.
