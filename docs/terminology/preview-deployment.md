# preview deployment

An isolated static-site deployment used to inspect a proposed change before replacing the main site. Static-site previews receive its own deployment identity and URL. The site guide describes how to create and remove it.

See [Static hosting](../../docs/user/static-hosting.md) for the full contract and operating procedure.
