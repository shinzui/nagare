# domain mapping

The Knative resource that routes an optional public hostname to a Nagare service. Nagare also supplies automatic internal app domains. A public domain requires the related DNS and TLS configuration.

See [Deploying apps](../../docs/user/deploying-apps.md) for the full contract and operating procedure.
