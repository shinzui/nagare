# auth portal

The operator-owned sign-in entry point for Nagare sites protected by identity-aware access. The portal handles browser login and hands session information to Nagare's access enforcer. It is distinct from the application it protects.

See [Auth portal](../../docs/user/auth-portal.md) for the full contract and operating procedure.
