# server site

A Nagare site whose framework build runs as an origin server inside a Node.js image. A `ServerSite` supports server rendering, functions, and API routes. It shares the site deploy command and Knative runtime model with static sites.

See [Static hosting](../../docs/user/static-hosting.md) for the full contract and operating procedure.
