# task app association

The optional link that lets a scheduled task inherit a deployed app image and runtime environment. Associated tasks carry the app label and are addressed through the app name. An app-less task is addressed with the CLI `-` sentinel.

See [Scheduled tasks](../../docs/user/scheduled-tasks.md) for the full contract and operating procedure.
