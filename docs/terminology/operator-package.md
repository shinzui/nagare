# operator package

The Nagare Nix output that includes the CLI, immutable platform payload, recipe launcher, and operator tooling. Install `#nagare` for infrastructure and platform operations. The smaller `#nagarectl` output serves application commands on an existing target.

See [Installation](../../docs/user/installation.md) for the full contract and operating procedure.
