# release payload

The immutable platform files packaged with a versioned Nagare release for operator recipes. The `nagare` launcher resolves this payload to a writable context workspace. Commands use the selected release instead of depending on a source checkout.

See [Installation](../../docs/user/installation.md) for the full contract and operating procedure.
