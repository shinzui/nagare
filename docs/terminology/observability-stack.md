# observability stack

The Nagare services that collect and display metrics, logs, and traces from the platform and apps. VictoriaMetrics, VictoriaLogs, VictoriaTraces, an OpenTelemetry Collector, and Grafana make up the stack.

See [Observability](../../docs/user/observability.md) for the full contract and operating procedure.
