# Nagare

A single-node personal application platform that deploys and operates projects on a cloud or local Kubernetes cluster. Nagare combines a host, cluster services, and operator commands so many small projects can share one target. Cloud mode uses a GCP VM; local mode uses k3d.

See [Readme](../../README.md) for the full contract and operating procedure.
