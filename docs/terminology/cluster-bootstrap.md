# cluster bootstrap

The installation and configuration of Nagare services on an existing k3s or k3d cluster. Bootstrap installs Knative, ingress, certificate management, and other selected components after the host or local cluster exists.

See [Cluster bootstrap](../../docs/user/cluster-bootstrap.md) for the full contract and operating procedure.
