# Nagare 0.16.2

The platform's own databases can be restored after losing the VM, and sign-in works afterward. The first real restore showed that a rebuild brought the rows back but Shōmei would not start and En could not find its grants. A disposable context has since lost its VM and come back from its backups with no hand fixes: the same account signed in, 85 minutes after the VM was deleted.

## Fixed

- **A rebuild restores En and Shōmei before they start** ([F144](../audits/mp23-findings.md)). The review holds both services until `db restore-rebuilt` has loaded their data.
- **Shōmei's key-encryption key is escrowed** ([F146](../audits/mp23-findings.md)). It wraps Shōmei's signing keys and TOTP secrets and lived only in the cluster. `db escrow-signing-key shomei-db` now saves it too, and a recreated Secret reuses it. An escrow file that can't be read stops the apply instead of generating a new key.
- **A restored En can read its grants** ([F147](../audits/mp23-findings.md)). En stamps grants with PostgreSQL transaction IDs, and a dump doesn't carry the counter, so a correct password got a 503. En's restore Job now moves the counter past the restored rows and rotates En's datastore ID.
- **Re-escrowing after a rebuild works** ([F148](../audits/mp23-findings.md)). The command refused because the database is new. The old file now moves aside, since older backups still need it.

## Upgrade notes

Run `nagarectl db escrow-signing-key shomei-db -n nagare-system` on each context, and commit the encrypted files. A context with no escrowed key can't restore Shōmei's signing keys or TOTP enrolments after losing the VM.

A second VM loss before a rebuilt database's first backup has no reviewed restore ([F149](../audits/mp23-findings.md)). The backups stay in the bucket.

## Compatibility and rollback

`transitionsFrom` adds 0.16.1. The inventory, journal, review and snapshot formats are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
