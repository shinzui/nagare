# Nagare 0.25.1

A release that changes only the CLI. It carries no platform, host or image change, so upgrading a
context from 0.25.0 applies nothing to it (MasterPlan 37 D1).

## Changed

- Nothing beyond the version. Every service image keeps its 0.25.0 digest and store path.

## Upgrade notes

No config change is needed. Upgrading from 0.25.0 plans no host activation, publishes no image and
writes nothing to the cluster; `platform transition commit` moves the context pin alone. Deployers
move to the 0.25.1 CLI and re-plan; a review saved with an older CLI is refused at apply.

## Compatibility and rollback

`transitionsFrom` adds 0.25.0. Existing records, journals, reviews and snapshots are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
