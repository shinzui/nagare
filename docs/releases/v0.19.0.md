# Nagare 0.19.0

An operator can delegate a bounded part of a context to a named deployer, such as a CI runner, so engineers deploy by pushing ([MasterPlan 33](../masterplans/33-delegate-a-bounded-part-of-a-context-to-a-ci-deployer-so-engineers-deploy-by-pushing.md), [ADR 35](../adr/0035-a-delegated-deployer-is-trusted-and-repository-content-is-not.md)).

## Added

- **Reviewed delegations** ([EP-247](../plans/247-review-a-bounded-namespace-delegation-for-a-named-deployer-and-record-who-applied-each-change.md)). `delegation create NAME` reviews a delegation that gives a deployer its namespaces, hostname suffixes, workload kinds, image repository, team, build namespace and quotas. `delegation show NAME --contract 1` reads it back, and `delegation revoke NAME` ends it. A context with `NAGARE_DEPLOYER=NAME` is a deployer context: it can only propose changes inside its delegation, and every protected route it adds requires login.
- **Who applied each change.** `inventory history` names each transaction's actor (`operator` or `deployer:NAME`) and the deployer's source repository, revision and run (`--source-repository`, `--source-revision`, `--source-run`).
- **Deployer credentials** ([EP-248](../plans/248-issue-least-privilege-credentials-to-a-delegated-deployer.md)). `delegation credentials NAME --out DIR [--duration D]` writes one private bundle with Kubernetes, object-store and (on a cloud context) cloud credentials limited to the delegation. Running it again rotates them; revoking empties the deployer's roles and disables its cloud account. On a cloud context each delegation gets its own service account and Artifact Registry repository.
- **Deploy from a rendered configuration** ([EP-249](../plans/249-deploy-apps-and-static-sites-from-a-rendered-configuration-without-running-the-repository-s-program.md)). `app render`, `worker render` and `site render` write a configuration document, and `app|worker|site deploy --rendered FILE` deploys it without running the repository's program.
- **Delegation-wide site access** ([EP-250](../plans/250-open-a-delegated-namespace-s-sites-to-the-delegation-s-team-without-a-per-site-grant.md)). `access grant --delegation NAME --team TEAM` opens every protected site in a delegation's namespaces to a team, with no per-site grant and no access-service key for the deployer.
- **A local context's inventory in its object store** ([EP-251](../plans/251-keep-a-local-context-s-inventory-store-in-its-in-cluster-object-store-so-an-in-cluster-deployer-can-apply.md)). `inventory store migrate --to object` moves a local context's history into its in-cluster MinIO, so an in-cluster deployer can apply.
- **Static sites packaged without Docker** ([EP-252](../plans/252-package-a-static-site-image-archive-without-a-docker-daemon.md)). `site package --builder layered --base-archive FILE` builds the image archive with no Docker daemon, and the static base image is pinned by digest.
- **ARM64 Linux deploys.** `packages.aarch64-linux.nagarectl` now carries the platform payload, skopeo and jq, so it can deploy, not only render. It is still not a supported production host.

## Fixed

- **A saved review that another change overtook is refused as `review_stale`** (409, retryable), so a client re-plans. It was refused as `review_changed`, which is not retryable.
- **Image publication runs on a Linux host.** The transport hashes archives in process and runs through `bash` on `PATH`, instead of assuming `shasum`, `awk` and `/usr/bin/env`.

## Upgrade notes

No `Config.hs` source changes. The En schema ConfigMap and the `nagare-access` enforcer change, and the transition installs both. An enforcer older than this release treats a delegation-wide grant as an ordinary protected host and refuses it, so delegated access works only after the upgrade. A delegation on a cloud context needs the context's inventory in GCS.

## Compatibility and rollback

`transitionsFrom` adds 0.18.0. Operator reviews keep their bytes and the review stays version 1. A review written by a deployer or a named operator carries `actor`, which an older CLI refuses rather than misreads.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
