# Nagare 0.15.0

Nagare 0.15.0 takes the host kernel fix for CVE-2026-98432 and publishes the auth plane and admin API
as release images.

## Security

- **CVE-2026-98432.** The host kernel moves from 6.18.51 to 6.18.59. The flaw is a use-after-free in
  the IPv4 TCP handshake, reachable without credentials on any listening port, and is fixed in
  6.18.56. The new kernel runs only after the host boots, so reboot through the reviewed VM power
  path after the upgrade and check `uname -r`.

## Changed

- **Host nixpkgs moves to 2026-10-30.** With it come systemd 262, Tailscale 1.104.4, OpenSSH 10.6p1
  and a newer `sops-nix`.
- **The Kubernetes minor is pinned.** The new nixpkgs defaults to k3s 1.36. The host stays on the
  1.35 line through `k3s_1_35`, so this release takes only the patch from 1.35.8 to 1.35.9.

## Added

- **Release images.** En, Shōmei, nagare-access and the admin API are built from the release and
  published to public GHCR packages by digest. `release.json` names them, bootstrap and transitions
  select them by default, a reviewed digest override stays explicit, and a cluster no longer needs
  Cloud Build for them (EP-237).
- **Image status.** Platform status reports whether each of those workloads runs the release image,
  an override, a drifted image or an unknown one, and is exact only when running containers agree.

## Compatibility and rollback

`transitionsFrom` adds 0.14.1. The upgrade rolls the auth plane and its migration Jobs onto the
release images. Rollback is not claimed.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work
intranet running the candidate.
