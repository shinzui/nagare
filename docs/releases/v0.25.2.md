# Nagare 0.25.2

A release that changes only the CLI and the release tooling. It carries no platform, host or image
change, so upgrading a context from 0.25.1 applies nothing to it.

## Changed

- `nagarectl release publish` publishes a release as its signed tag, its notes and the upgrade
  rehearsal record, validated against the tag's `release.json`. The native output, clone-free,
  platform metadata and `SHA256SUMS` attachments are gone (MasterPlan 37 D3).
- A release candidate run resumes: rerunning it keeps the steps it finished. The upgrade rehearsal
  runs on a Colima profile it creates and deletes.

## Upgrade notes

No config change is needed. Upgrading from 0.25.1 plans no host activation, publishes no image and
writes nothing to the cluster; `platform transition commit` moves the context pin alone. Deployers
move to the 0.25.2 CLI and re-plan; a review saved with an older CLI is refused at apply.

## Compatibility and rollback

`transitionsFrom` adds 0.25.1. Existing records, journals, reviews and snapshots are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
