# Nagare 0.28.2

The lifecycle event worker no longer gets evicted while it verifies large backup archives.

## Fixed

- Since 0.28.0 the worker streams each backup archive it verifies to a scratch file instead of
  holding it in memory. Its `/tmp` volume was limited to 256Mi, so verifying the work intranet's
  999 MiB app-database archives evicted the Pod. The cloud worker's `/tmp` volume is now 6Gi, enough
  for four archives of that size verified at once.

## Upgrade notes

No config change is needed, and the service images keep their 0.28.1 digests.

## Compatibility and rollback

`transitionsFrom` adds 0.28.1.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
