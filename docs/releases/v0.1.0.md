# Nagare 0.1.0

Nagare 0.1.0 is the first Nix-distributed release candidate. It packages the typed `nagarectl`
runtime and the immutable platform assets needed for local and GCP operation, so an operator can pin
and run Nagare without a source checkout.

## Highlights

- Run the CLI or operator recipes from the immutable `v0.1.0` flake reference.
- Keep cloud and local targets isolated in named contexts under XDG configuration and state roots.
- Generate context-owned NixOS host flakes with explicit SSH keys and encrypted secret references.
- Inspect CLI, payload, context, host, and cluster versions before mutation.
- Plan, apply, resume, and explicitly roll back a staged per-context platform upgrade.

## Install

After the maintainer publishes the tag, inspect the CLI without cloning:

```bash
nix run github:shinzui/nagare/v0.1.0#nagarectl -- version --json
```

For a persistent profile installation:

```bash
nix profile install github:shinzui/nagare/v0.1.0#nagarectl
```

The tag remains unpublished until the release workflow and maintainer checklist have passed. Until
then, use the exact reviewed commit as a rehearsal reference.

## Compatibility and limits

The supported client systems are `x86_64-linux` and `aarch64-darwin`. Nix is the only supported
distribution channel in this release; there are no portable binary archives, Homebrew formulae, or
CLI container images. Cloud provisioning still requires the operator's GCP authentication, and local
operation requires Docker. Publishing a release never selects or upgrades a live context.

All capabilities remain experimental in 0.1.0. Preserve an existing context's prior payload and run
`nagarectl platform status` before changing its pinned version.
