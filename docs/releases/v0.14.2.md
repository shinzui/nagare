# Nagare 0.14.2

Nagare 0.14.2 takes the host kernel fix for CVE-2026-98432.

## Security

- **CVE-2026-98432.** The host kernel moves from 6.18.51 to 6.18.59. The flaw is a use-after-free in
  the IPv4 TCP handshake, reachable without credentials, and is fixed in 6.18.56. The new kernel runs
  only after the host boots, so reboot through the reviewed VM power path after the upgrade and check
  `uname -r`.

## Changed

- **Host nixpkgs moves to 2026-10-30.** With it come systemd 262, Tailscale 1.104.4, OpenSSH 10.6p1
  and a newer `sops-nix`. k3s stays on the 1.35 line through `k3s_1_35`, moving from 1.35.8 to 1.35.9.

## Compatibility and rollback

`transitionsFrom` adds 0.14.1. The inventory, journal, review and snapshot formats are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work
intranet running the candidate.
