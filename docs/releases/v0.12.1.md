# Nagare 0.12.1

Nagare 0.12.1 shortens a platform transition plan on a remote context. The v0.12.0 intranet move
took 7.6 minutes, but its stage plans took 89, 65 and 44 seconds, mostly waiting on work done
twice or one at a time (EP-224).

## Changed

- **A plan prepares the host closure once.** A stage with several host operations built and
  evaluated the target closure for each; it now builds it once and traces it as artifact
  preparation, reported beside the plan.
- **Observation reads at once.** Kubernetes and Helm observe concurrently, and each Helm release
  is read without waiting for the others.
- **A command opens each remote inventory store once.** Repeated opens no longer start a new
  gcloud session and prove the bucket's ownership again.

## Compatibility and rollback

`transitionsFrom` adds 0.12.0. The inventory, journal and review formats are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the
work intranet running the candidate.
