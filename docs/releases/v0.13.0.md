# Nagare 0.13.0

Nagare 0.13.0 makes publishing a static site one repeatable command and lets an operator push
signed Nix closures to the context's Attic cache from a workstation.

## Added

- **`nagarectl site publish`.** One command packages a static site, publishes its image and
  deploys it. Publishing unchanged files builds nothing and releases nothing; a failed stage keeps
  the release directory and prints the exact `--resume` command (EP-222).
- **`nagarectl site package --context-out DIR | --archive FILE`.** Packages a static site as a
  Docker build context or image archive, with a deterministic content digest, without deploying
  it (EP-222).
- **`site publish --contract 1`** prints one `site-publish-result` document.
- **`nagarectl nix-cache token`, `forward` and `push`.** `push STORE-PATH...` mints a short-lived
  token inside the cluster, forwards 127.0.0.1:18080 to the cache, pushes through the packaged
  Attic client and removes every credential on any exit. `token` writes a scoped token to a new
  mode-0600 file and `forward` holds the forward open for other producers. `push --endpoint URL
  --token-file FILE` pushes to any Attic with no cluster contact. Under `--contract 1`, `forward`
  prints `nix-cache-endpoint` and `push` prints `nix-cache-push-result` (EP-230).

## Changed

- **Image builds without Build Secrets reuse Docker's layer cache.** A build with Build Secrets
  still builds every layer fresh.

## Compatibility and rollback

`transitionsFrom` adds 0.12.1. The inventory, journal and review formats are unchanged; the new
contract documents are additions to contract version 1.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the
work intranet running the candidate.
