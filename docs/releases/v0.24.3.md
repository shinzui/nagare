# Nagare 0.24.3

A cloud delegated deployer can publish images to its delegation's own repository.

## Fixed

- **`app image-plan` accepts a cloud deployer's own repository.** A cloud delegation must publish to its own repository in the context's project (FRIC-82, `mori://shinzui/kotei/okf/friction-log/concepts/FRIC-82`). `app image-plan` still required every destination to be in the platform repository its context names, so it refused every image a delegated deployer could publish ("image destination must be a tagged image in the active context registry"). In a deployer context it now accepts a tagged image in any repository of the context's project. Admission still holds the destination to the delegation's image repository. An operator context is unchanged.

## Upgrade notes

No config change is needed. A deployer uses the 0.24.3 CLI.

## Compatibility and rollback

`transitionsFrom` adds 0.24.2. Existing records, journals, reviews and snapshots are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the work intranet running the candidate.
