# Nagare 0.14.1

Nagare 0.14.1 makes the platform-versions document list every managed database server. 0.14.0
looked for servers only in a scope kind Nagare does not have, so it listed none.

## Fixed

- **Database servers from every owning scope.** A database server is any accepted StatefulSet
  labelled with its engine, whether the platform (`en-db`, `shomei-db`), a shared standalone server
  or an application owns it. It is reported once, under `databases`, with its declared version
  beside the version it reports, and no longer also as a component (EP-236).
- **A server's instances are its own pods.** Pods are counted for a workload only when the workload
  controls them, so a scheduled backup Job's pods, which carry the server's labels, are no longer
  reported as failed instances.
- **The post-apply refresh covers standalone servers.** A converged apply that changes a
  `platform:` or `standalone:` scope refreshes the snapshot.

## Compatibility and rollback

`transitionsFrom` adds 0.14.0. The inventory, journal, review and snapshot formats are unchanged.

## Validation

A green full gate, the EP-172 upgrade rehearsal reading its seeded row back unchanged, and the
work intranet running the candidate.
